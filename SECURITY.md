# Política de segurança

## Relatar vulnerabilidade

Não abra issue pública para vulnerabilidade, token exposto ou possível acesso indevido. Abra uma [Security Advisory privada](https://github.com/victorgabrieldeon/futhub/security/advisories/new) com:

- descrição e impacto;
- passos mínimos de reprodução;
- versão ou commit afetado;
- mitigação conhecida, se houver.

Não inclua credenciais reais nem dados de jogadores. Mantenedores confirmam recebimento, analisam impacto e coordenam correção antes de divulgação.

## Escopo

Relate problemas em aplicações, pacotes, infraestrutura versionada e workflows deste repositório. Dependências vulneráveis também são bem-vindas quando acompanhadas de versão afetada.
