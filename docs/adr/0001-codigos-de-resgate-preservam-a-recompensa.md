# Códigos de resgate preservam a recompensa concedida

Cada Código de resgate referencia um Item dedicado. Administradores podem visualizar o código canônico em texto e trocar código ou Item somente antes do primeiro Resgate; depois disso, ambos ficam imutáveis para preservar o significado do histórico. Essa escolha favorece operação simples e auditoria fiel, aceitando Items exclusivos por campanha e armazenamento legível porque os códigos são promoções universais, não credenciais individuais.
